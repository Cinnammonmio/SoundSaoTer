# เซิร์ฟเวอร์คลังเสียงกลาง

Worker เล็ก ๆ ตัวนี้ทำอย่างเดียว: รับไฟล์เสียงที่คนกดส่งจากในโปรแกรม เอาไปกองไว้ใน
repo คิวส่วนตัว แล้วรอให้เจ้าของคลังกดอนุมัติในโปรแกรม ไฟล์ถึงจะย้ายขึ้น repo สาธารณะ

**ทำไมต้องมี** — GitHub ไม่ให้เขียนไฟล์โดยไม่มีตัวตน ถ้าฝัง token ไว้ในตัว `.exe`
ใครก็แกะออกมาได้ แล้ว GitHub จะเพิกถอน token นั้นทิ้งเองเมื่อเจอในที่สาธารณะ
token จึงต้องอยู่ฝั่งเซิร์ฟเวอร์ที่เดียว ส่วน **การโหลดเสียงไม่ผ่านตัวนี้เลย** —
โปรแกรมดึงจาก URL ของ GitHub ตรง ๆ จึงไม่เปลืองโควตา Worker และไม่มีค่าใช้จ่าย

ฟรีทั้งหมดในโควตา Cloudflare (100,000 ครั้ง/วัน)

## ติดตั้งครั้งแรก

ทำในโฟลเดอร์ `worker/` นี้

**1. ล็อกอิน Cloudflare** (เปิดเบราว์เซอร์ให้กด Allow)

```bash
npx wrangler login
```

**2. สร้างที่นับโควตา แล้วเอา id ไปใส่ใน `wrangler.toml`**

```bash
npx wrangler kv namespace create RATE
```

คำสั่งจะพิมพ์ `id = "xxxxxxxx..."` ออกมา — ก๊อปไปวางแทน `ใส่-id-ที่ได้จากคำสั่ง-kv-namespace-create`

**3. สร้าง GitHub token ให้เซิร์ฟเวอร์**

ที่ https://github.com/settings/personal-access-tokens/new

| ช่อง | ใส่ |
|---|---|
| Token name | `soundsaoter-hub-worker` |
| Expiration | ยาวที่สุดที่ยอมรับได้ (หมดอายุแล้วต้องตั้งใหม่) |
| Repository access | Only select repositories → **soundsaoter-hub** และ **soundsaoter-hub-queue** |
| Permissions → Repository → Contents | Read and write |

แล้วเอา token มาใส่ (คำสั่งจะถามแล้วให้วาง ไม่ขึ้นบนจอ)

```bash
npx wrangler secret put GITHUB_TOKEN
```

**4. ตั้งกุญแจผู้ดูแล** — สุ่มมาสัก 32 ตัวอักษร เก็บไว้ใช้กดอนุมัติในโปรแกรม

```bash
npx wrangler secret put ADMIN_KEY
```

**5. ปล่อยขึ้นเซิร์ฟเวอร์**

```bash
npx wrangler deploy
```

จะได้ URL หน้าตาแบบ `https://soundsaoter-hub.ชื่อคุณ.workers.dev` — เอาไปใส่ในโปรแกรม
ที่ **🌐 คลังกลาง → ⚙ ผู้ดูแล → ที่อยู่เซิร์ฟเวอร์** พร้อมกุญแจผู้ดูแลจากข้อ 4

## เช็กว่าใช้ได้

```bash
curl https://soundsaoter-hub.ชื่อคุณ.workers.dev/
```

ตอบ `{"ok":true,"sounds":0,"maxMb":8}` คือเรียบร้อย

## ปรับทีหลัง

- แก้โควตา/ขนาดไฟล์ใน `[vars]` ของ `wrangler.toml` แล้ว `npx wrangler deploy` ใหม่
- ดู log สด ๆ: `npx wrangler tail`
- ปิดรับเสียงชั่วคราว: `npx wrangler delete` (คลังเก่ายังโหลดได้ตามปกติ เพราะโหลดไม่ผ่าน Worker)

## ปลายทางทั้งหมด

| วิธี | ปลายทาง | ใคร | ทำอะไร |
|---|---|---|---|
| GET | `/` | ใครก็ได้ | สถานะ + จำนวนเสียงในคลัง |
| POST | `/upload` | ใครก็ได้ | ส่งไฟล์เสียงเข้าคิว (จำกัดขนาด ชนิดไฟล์ และจำนวนต่อ IP) |
| GET | `/pending` | ผู้ดูแล | รายการที่รอตรวจ |
| GET | `/file/:id` | ผู้ดูแล | ไฟล์ในคิว ไว้ฟังก่อนตัดสิน |
| POST | `/approve` | ผู้ดูแล | ย้ายขึ้นคลังสาธารณะ |
| POST | `/reject` | ผู้ดูแล | ทิ้งจากคิว |
| POST | `/remove` | ผู้ดูแล | เอาเสียงที่ขึ้นคลังไปแล้วออก |

## ข้อควรรู้

- คลังเป็น **สาธารณะ** ใครมีลิงก์ก็โหลดได้ อนุมัติเฉพาะเสียงที่เรามีสิทธิ์เผยแพร่
  (เสียงที่อัดเอง เสียงสังเคราะห์ เสียงที่เจ้าของอนุญาต) เสียงที่ตัดจากเพลงหรือคลิปของคนอื่น
  เจ้าของลิขสิทธิ์แจ้งลบได้ และถ้าโดนแจ้งบ่อย GitHub ปิด repo ได้
- กุญแจผู้ดูแลคือสิ่งเดียวที่กั้นการอนุมัติ/ลบ — อย่าแปะในแชตหรือที่สาธารณะ
  ถ้าหลุดให้ `npx wrangler secret put ADMIN_KEY` ตั้งใหม่ ของเก่าใช้ไม่ได้ทันที
- โปรแกรมฝั่งผู้ใช้ไม่มี token หรือกุญแจอะไรอยู่เลย มีแต่ที่อยู่เซิร์ฟเวอร์
