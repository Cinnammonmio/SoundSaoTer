===============================================
  SOUNDSAOTER  —  ส่งไฟล์เสียงเข้าไมค์ในเกม
===============================================

กดคีย์ลัด แล้วไฟล์เสียงจะถูกส่งออกเป็น "ไมค์"
ให้เพื่อนในเกมได้ยิน (Dota 2, PUBG, Discord ฯลฯ)
ยังพูดคุยด้วยเสียงตัวเองได้ตามปกติ

-----------------------------------------------
ขั้นตอนที่ 1 : ติดตั้ง VB-CABLE  (จำเป็น)
-----------------------------------------------
Windows ไม่เปิดให้โปรแกรมยัดเสียงเข้าไมค์จริงได้
ต้องสร้าง "ไมค์ปลอม" ขึ้นมาก่อน

  1. ใช้ไฟล์  VBCABLE_Driver_Pack45.zip  ที่แนบมาในโฟลเดอร์นี้
     (หรือโหลดใหม่จาก  https://www.vb-cable.com )
  2. แตกไฟล์ zip
  3. คลิกขวาที่  VBCABLE_Setup_x64.exe
     เลือก  Run as administrator
  4. กด  Install Driver
  5. รีสตาร์ตคอมพิวเตอร์   << ข้ามไม่ได้

-----------------------------------------------
ขั้นตอนที่ 2 : เปิดโปรแกรม
-----------------------------------------------
ดับเบิลคลิก  SoundSaoTer.exe

* ครั้งแรก Windows อาจขึ้นหน้าจอฟ้า
  "Windows protected your PC"
  เป็นเพราะไฟล์ยังไม่ได้เซ็นใบรับรอง (ซึ่งมีค่าใช้จ่าย)
  ไม่ใช่ไวรัส  ->  กด "More info" แล้วกด "Run anyway"

* เปิดครั้งแรกอาจช้า 5-10 วินาที ครั้งต่อไปจะเร็วขึ้น

-----------------------------------------------
ขั้นตอนที่ 3 : ตั้งค่าในโปรแกรม
-----------------------------------------------
  เสียงเข้าเกม     ->  CABLE ... (VB-Audio Virtual Cable)
                       (ถ้ามีหลายตัว เลือกตัวที่ขึ้น WASAPI)
  ฟังเองที่หูฟัง   ->  หูฟัง/ลำโพงของตัวเอง
  ไมค์จริง         ->  ไมค์ตัวจริงของตัวเอง
                       << ไม่ตั้งช่องนี้ = พูดแล้วเพื่อนไม่ได้ยิน

ลองพูดใส่ไมค์ แถบ "ระดับเสียงไมค์" ต้องขยับ

-----------------------------------------------
ขั้นตอนที่ 4 : ตั้งค่าในเกม
-----------------------------------------------
Dota 2 :  Settings > Audio > Voice/Microphone Device
          เลือก  CABLE Output (VB-Audio Virtual Cable)

เกมอื่นก็เหมือนกัน หาเมนูเลือกไมค์
แล้วเลือก CABLE Output

-----------------------------------------------
ขั้นตอนที่ 5 : ใส่เสียงแล้วตั้งปุ่ม
-----------------------------------------------
  * ปุ่ม "โหลดเสียงจากเว็บ"
      เลือกเว็บ Dota 2 / Myinstants / TiengDong
      พิมพ์ค้นหาแล้วกดโหลดได้เลย
      (TiengDong: เลือกหมวดก่อน แล้วพิมพ์กรอง)
  * ปุ่ม "✂ ตัดจาก YouTube"
      วางลิงก์คลิป -> ลากเลือกช่วงบนภาพ (ล้อเมาส์ = ซูม)
      -> ▶ ฟังก่อน -> บันทึกลงคลังเสียง
  * ปุ่ม "เพิ่มไฟล์" / "เพิ่มทั้งโฟลเดอร์"
      ใช้ไฟล์ mp3 / wav / ogg / flac ของตัวเอง

  * เมนูข้างช่องค้นหา = เรียงลำดับ (ใหม่ล่าสุด / เก่าสุด / ชื่อ)
      ค่าเริ่มต้นคือใหม่ล่าสุด เสียงที่เพิ่งได้มาจะอยู่บนสุด

  * หรือก๊อปไฟล์ใส่โฟลเดอร์ sounds ที่อยู่ข้าง ๆ ตัวโปรแกรม
      แล้วเปิดโปรแกรมใหม่ มันจะสแกนเข้ารายการให้เอง

  ตั้งคีย์ลัด (แท็บ "ช่องคีย์ลัด")
    แต่ละ slot = ปุ่ม 1 ปุ่ม + เสียงกี่เสียงก็ได้
    กดป้าย "+ ตั้งปุ่ม"   -> กดปุ่มที่ต้องการ
    กดที่ชื่อเสียง       -> หน้าเลือกเสียง พิมพ์ค้นหาได้
                            กดชื่อเสียงเพื่อเลือก กดซ้ำเพื่อเอาออก
                            เลือกหลายเสียง = กดปุ่มลัดทีเดียวได้เสียงสุ่ม
    ปุ่ม 🎲 / 🔁 ในแถว   -> สลับ สุ่ม / เรียงตามลำดับ
    คลิกขวาที่ป้ายปุ่ม   -> ล้างปุ่ม
    slot 1 = สุ่มทั้งคลังเสมอ

  ปุ่ม 🗣 พิมพ์ให้อ่าน
    พิมพ์ข้อความ -> ได้เสียง "แจ้งเตือน + อ่านข้อความ"
    เลือกภาษา เสียงแจ้งเตือน และจังหวะเว้นได้
    กดบันทึกแล้วเสียงจะอยู่ในคลัง เอาไปใส่ slot กดจากปุ่มลัดได้
    (ต้องต่อเน็ต เพราะใช้เสียงอ่านของ Google Translate)

  ปุ่ม 🤝 แชร์เสียง
    อัปเสียงของตัวเองขึ้น GitHub (repo ส่วนตัว) ทีละเสียง
    แล้วส่ง "รหัสชุดเสียง" ให้เพื่อนวางในโปรแกรมของเขา
    เพื่อนกดโหลดทีละเสียงได้ · เสียงที่มีอยู่แล้วข้ามให้เอง
    !! ใครได้รหัสนี้ เข้าถึง repo เสียงของคุณได้ ส่งเฉพาะคนที่ไว้ใจ

  ปุ่ม 📱 มือถือ
    เปิดสวิตช์ แล้วสแกน QR ด้วยมือถือ (Wi-Fi เดียวกัน)
    มือถือกลายเป็นแผงกดเสียง · ครั้งแรกถ้า Windows ถาม
    เรื่องไฟร์วอลล์ ให้ติ๊ก Private network แล้วกด Allow

  ปุ่ม 🎚 ปรับเสียงไมค์ (แถวมิเตอร์ไมค์)
    ตัดเสียงรบกวน (AI) / ตัดไมค์ตอนไม่พูด / ปรับความดังอัตโนมัติ
    เหมือนในตั้งค่าเสียงของ Discord · ใช้หูฟังจะดีที่สุด

  !! อย่าใช้ปุ่มที่ต้องกดในเกม (Q W E R, 1-9, F1-F12)
     เพราะ Windows จะกินปุ่มนั้นไว้ ไม่ส่งต่อให้เกม
     แนะนำปุ่ม numpad หรือ ctrl+alt+อะไรก็ได้

-----------------------------------------------
ของที่ช่วยตอนเล่น
-----------------------------------------------
  ปุ่ม 🔊 ในแต่ละแถว  = ปรับดังเบาเฉพาะเสียงนั้น
                        (เลื่อนล้อเมาส์บนปุ่มก็ได้)
  slot 1 🎲          = สุ่มเล่นหนึ่งเสียง
  ปุ่ม ⚙ ตั้งค่า (ขวาล่าง) = สีธีม, กันสแปม, เปิดพร้อม Windows
  ปุ่ม ☀ / 🌙 (ขวาบน)   = สลับโหมดมืด / สว่าง

  กันสแปม (ค่าเริ่มต้น 2 วินาที)
     กดคีย์ลัดรัว ๆ จะเล่นแค่ครั้งเดียวต่อ 2 วินาที
     ช่วยไม่ให้โดนรีพอร์ตว่าสแปมเสียง

-----------------------------------------------
วิธีใช้ตอนเล่นเกม
-----------------------------------------------
กด push-to-talk ค้างไว้  แล้วกดคีย์ลัด

ctrl+alt+s = หยุดเสียงทันที (เปลี่ยนได้)
สวิตช์ "ฮอตคีย์" = ปิดคีย์ลัดชั่วคราวตอนไม่ได้เล่นเกม

-----------------------------------------------
ปัญหาที่เจอบ่อย
-----------------------------------------------
ไม่เห็น CABLE ในรายการ
   -> ยังไม่ได้รีสตาร์ตหลังติดตั้ง / กด "รีเฟรชอุปกรณ์"

เลือก CABLE แล้วขึ้น error สีแดง
   -> ลองเลือก CABLE ตัวอื่นในรายการ
      (บางเครื่องมีรายการผีที่เปิดไม่ได้)

พูดแล้วเพื่อนไม่ได้ยิน
   -> ยังไม่ได้ตั้งช่อง "ไมค์จริง"

เสียงสะท้อน / หอน
   -> ไปตั้ง CABLE Output เป็นช่อง "ไมค์จริง" อยู่
      ให้เปลี่ยนเป็นไมค์ตัวจริง

ฮอตคีย์ไม่ทำงาน
   -> ปุ่มชนกับโปรแกรมอื่น ดูข้อความล่างสุดของหน้าต่าง
      แล้วเปลี่ยนปุ่ม

เพื่อนได้ยินเบามาก
   -> เพิ่มสไลเดอร์ "เสียงเข้าเกม"
      และเพิ่ม Levels ของ CABLE Output ใน Windows

ข้อควรรู้
-----------------------------------------------
VB-CABLE เป็นผลงานของ VB-Audio Software (www.vb-cable.com)
เป็น donationware ใช้ฟรี แนบมาให้แบบไฟล์ต้นฉบับไม่ได้แก้ไข
ถ้าชอบ ช่วยสนับสนุนผู้พัฒนาได้ที่เว็บของเขา

โปรแกรมนี้ไม่แตะตัวเกมเลย ไม่อ่าน/แก้ memory
ไม่ inject อะไร ไม่ส่งปุ่มปลอมเข้าเกม
เป็นแค่โปรแกรมเล่นไฟล์เสียง ระดับเดียวกับ Discord

แต่ระวังเรื่องสแปมเสียงใส่ voice chat
โดนรีพอร์ตเยอะ ๆ ติด comms ban ได้ ใช้พอประมาณ
