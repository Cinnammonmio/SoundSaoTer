## ติดตั้ง

1. แตกไฟล์ zip ไว้ที่ไหนก็ได้
2. คลิกขวา `VBCABLE_Setup_x64.exe` → **Run as administrator**
3. กด **Install Driver**
4. **รีสตาร์ตเครื่อง** (ข้ามไม่ได้)
