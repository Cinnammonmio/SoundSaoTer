# SoundSaoTer — ส่งไฟล์เสียงเข้าไมค์ในเกม

กดคีย์ลัด → ไฟล์เสียงในเครื่องถูกส่งออกเป็น "ไมค์" ให้คนอื่นในเกม (Dota 2, Discord, ฯลฯ) ได้ยิน

## ทำไมต้องมี Virtual Cable

Windows ไม่เปิดให้โปรแกรมใด ๆ ยัดเสียงเข้าไมค์จริงได้ ต้องสร้าง "ไมค์ปลอม" ขึ้นมาก่อน
โปรแกรมนี้เล่นเสียงออก **CABLE Input** แล้วเกมรับเสียงจาก **CABLE Output** เหมือนเป็นไมค์ตัวหนึ่ง

```
ไฟล์ mp3 ─┐
          ├→ soundboard.py → CABLE Input (ลำโพงปลอม) ══ CABLE Output (ไมค์ปลอม) → Dota 2
ไมค์จริง ─┘                └→ หูฟังของเรา (monitor, จะเปิดหรือไม่ก็ได้)
```

โปรแกรมผสม **ไมค์จริง + ไฟล์เสียง** เข้า cable เส้นเดียวกัน เลยยังพูดคุยได้ปกติ

## ติดตั้ง

1. **VB-CABLE** — แนบไว้ให้แล้วใน [vbcable/](vbcable/) (ไฟล์ต้นฉบับจาก https://www.vb-cable.com)
   แตกไฟล์ → คลิกขวา `VBCABLE_Setup_x64.exe` → **Run as administrator** → Install Driver → **รีสตาร์ตเครื่อง**
   VB-CABLE เป็น donationware ของ VB-Audio ไม่ใช่ของโปรเจกต์นี้ — ถ้าชอบช่วยสนับสนุนผู้พัฒนาได้
2. **Python 3.14** + ไลบรารี (ติดตั้งไว้ให้แล้วในเครื่องนี้ ที่โฟลเดอร์ `.venv`):
   ```
   py -3.14 -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```
   `run.bat` กับ `build.py` เลือกใช้ `.venv` ให้เอง ไม่ว่าคำสั่ง `python` ในเครื่องจะชี้ไปรุ่นไหน

## อัปเดตอัตโนมัติ

โปรแกรมตรวจหาเวอร์ชันใหม่ให้เองตอนเปิด (หลังเปิด 2.5 วินาที) ถ้ามีของใหม่
ปุ่ม "ตรวจอัปเดต" มุมขวาล่างจะเปลี่ยนเป็นสีชมพู **"อัปเดต vX.Y.Z"** พร้อมแจ้งเตือนที่ tray

กดแล้วมันจะโหลด → ตรวจ sha256 → สลับตัวเอง → เปิดใหม่ให้ ไม่ต้องไปโหลดเองอีก

### ออกเวอร์ชันใหม่ยังไง

```
1. แก้ VERSION กับ CHANGES ใน version.py
2. python build.py
3. python publish.py
```

`publish.py` จะสร้าง GitHub release ตามเลขเวอร์ชัน อัป exe ขึ้นไป แล้วเขียน `latest.json`
ที่ทุกเครื่องใช้ตรวจอัปเดต — เพื่อนที่ถือเวอร์ชันเก่าจะเห็นปุ่มอัปเดตเด้งเองในการเปิดครั้งถัดไป

| ไฟล์ | หน้าที่ |
|---|---|
| [version.py](version.py) | เลขเวอร์ชัน, รายการที่เปลี่ยน, ที่อยู่ไฟล์ประกาศ |
| [updater.py](updater.py) | ตรวจ/โหลด/สลับตัวเอง พร้อมตรวจ sha256 ก่อนติดตั้ง |
| [publish.py](publish.py) | อัปขึ้น GitHub Releases |

ถ้าโหลดมาแล้วลายนิ้วมือไม่ตรง หรือไฟล์เล็กผิดปกติ โปรแกรมจะไม่ติดตั้งและเก็บตัวเดิมไว้
การสลับไฟล์ใช้วิธีเปลี่ยนชื่อตัวเก่าเป็น `.old` (Windows ห้ามเขียนทับ exe ที่กำลังรัน แต่ยอมให้เปลี่ยนชื่อ)
ถ้าย้ายตัวใหม่เข้าที่ไม่สำเร็จจะย้อนตัวเก่ากลับมาให้อัตโนมัติ

## สร้าง .exe ส่งให้เพื่อน

```
python build.py
```

ได้ **`dist/SoundSaoTer.exe`** (~56 MB เพราะรวม ffmpeg ของตัวตัดเสียง YouTube) ไฟล์เดียวจบ เพื่อนไม่ต้องมี Python
สคริปต์จะเตรียมโฟลเดอร์ `dist/ส่งให้เพื่อน/` ที่มี exe + [อ่านก่อนใช้.txt](อ่านก่อนใช้.txt) + ตัวติดตั้ง VB-CABLE + โฟลเดอร์ `sounds/` ให้พร้อมซิปส่งเลย

- `config.json` กับ `sounds/` จะถูกสร้างข้าง ๆ ตัว exe → ย้ายโฟลเดอร์ไปไหนก็พกค่าไปด้วย
- ไฟล์ไม่ได้เซ็น certificate ครั้งแรกจะโดน SmartScreen เตือน → **More info → Run anyway**
- เปลี่ยนไอคอนได้ที่ [make_icon.py](make_icon.py) แล้วรัน `python make_icon.py`

## ตั้งค่าเสียงใน Windows

- **Sound → Recording → CABLE Output** → คลิกขวา → Properties → แท็บ **Listen**
  ถ้าติ๊ก "Listen to this device" จะได้ยินเสียงตัวเองด้วย (หรือใช้ช่อง "ฟังเองที่หูฟัง" ในโปรแกรมแทนก็ได้ — แนะนำอันนี้มากกว่า เพราะไม่ทำให้เสียงดีเลย์)
- **CABLE Output → Levels** ตั้งไว้ประมาณ 70–100

## ตั้งค่าใน Dota 2

Settings → Audio → **Voice / Microphone Device** → เลือก `CABLE Output (VB-Audio Virtual Cable)`
แล้วใช้ปุ่ม push-to-talk ตามปกติ: กด push-to-talk ค้างไว้ แล้วกดคีย์ลัดของ soundboard

## ยังพูดเองได้ไหม

ได้ — แต่ **ต้องตั้งช่อง "ไมค์จริง (ส่งเข้าเกมด้วย)" ในโปรแกรมก่อน**

พอเปลี่ยนไมค์ในเกมเป็น CABLE Output แล้ว เกมจะได้ยินเฉพาะสิ่งที่ส่งเข้า CABLE Input เท่านั้น
ไมค์จริง (Yeti GX ฯลฯ) จะเงียบไปเลย ถ้าไม่ได้ส่งต่อเข้า cable

โปรแกรมนี้อ่านไมค์จริงแล้วผสมเข้า CABLE Input ให้ เลยได้ทั้งเสียงพูดและ soundboard พร้อมกัน
แถบระดับเสียงข้าง ๆ จะขยับตามเสียงพูด ใช้เช็คได้ว่าไมค์เข้าจริง

- ดีเลย์เสียงพูดที่เพิ่มขึ้นประมาณ 20–60 ms (คนอื่นแทบไม่รู้สึก)
- ติ๊ก **ปิดไมค์ชั่วคราว** = mute ไมค์จริง เหลือแต่ soundboard
- **อย่า** เลือก `CABLE Output` เป็นช่องไมค์จริง จะเกิด feedback loop

### ทางเลือกที่ไม่ต้องพึ่งโปรแกรมนี้

| วิธี | ข้อดี | ข้อเสีย |
|---|---|---|
| ช่อง "ไมค์จริง" ในโปรแกรม | ไม่ต้องลงอะไรเพิ่ม เปิด/ปิดง่าย | ต้องเปิดโปรแกรมค้างไว้ |
| Windows: Sound → Recording → **ไมค์จริง** → Properties → **Listen** → ติ๊ก Listen to this device → Playback through **CABLE Input** | Windows จัดการให้ ไม่ต้องเปิดโปรแกรม | ดีเลย์สูงกว่า, ลืมปิดแล้วงง |
| VoiceMeeter Banana | ดีเลย์ต่ำสุด ปรับ EQ/compressor ได้ | ต้องลง driver เพิ่ม เรียนรู้นาน |

## วิธีใช้

`run.bat` (จาก source) หรือ `dist/SoundSaoTer.exe`

**แถวอุปกรณ์ 3 ช่อง**

- 🎮 **เสียงเข้าเกม** → ตัว `CABLE ...` ที่เป็น WASAPI
  โปรแกรมเลือกให้อัตโนมัติตอนเปิดครั้งแรก โดย**ทดลองเปิดจริงก่อน** ไม่ได้เดาจากชื่อ
- 🎧 **ฟังเองที่หูฟัง** → หูฟังตัวเอง (เลือก `— ไม่ใช้ —` ถ้าไม่อยากได้ยิน)
- 🎤 **ไมค์จริง** → ไมค์ตัวจริง เพื่อให้ยังพูดคุยได้ตามปกติ
  แถบ **ระดับเสียงไมค์** ใต้ช่องจะขยับตามเสียงพูด ใช้เช็คว่าไมค์เข้าจริง

**แท็บ 🎯 ช่องคีย์ลัด (slot)**

คีย์ลัดผูกกับ **slot** ไม่ได้ผูกกับเสียง — แต่ละ slot มีปุ่มหนึ่งปุ่ม และ**ใส่ได้หลายเสียง**
มีเสียงเป็นร้อยก็ไม่ต้องเลื่อนหา ใช้แค่รายการ slot ไม่กี่แถว

| ส่วนของแถว | ทำอะไร |
|---|---|
| ป้ายปุ่ม (เช่น `ctrl+alt+1`) | คลิกเพื่อตั้งปุ่ม / คลิกขวาเพื่อล้าง — ถ้าปุ่มนี้อยู่ slot อื่นจะย้ายมาให้ |
| ชื่อเสียง (หรือ `3 เสียง · ...`) | คลิกเพื่อเปิด **หน้าเลือกเสียง** |
| 🎲 / 🔁 | โผล่เมื่อ slot มีมากกว่า 1 เสียง — คลิกสลับ **สุ่ม** ↔ **เรียงตามลำดับ** |
| ▶ | เล่นทดสอบ |
| ✕ | ลบ slot นี้ |

**ใส่หลายเสียงใน slot เดียว** — กดปุ่มลัดทีเดียวแล้วได้เสียงไม่ซ้ำเดิม

- **🎲 สุ่ม** (ค่าเริ่มต้น) = สุ่มจากเสียงใน slot นั้น ไม่ซ้ำตัวเดิมติดกัน
- **🔁 เรียงตามลำดับ** = ไล่ทีละเสียงตามลำดับที่เลือกไว้ แล้ววนกลับ
- ใช้ได้ทั้งปุ่มลัดในเกม ปุ่ม ▶ ในโปรแกรม และการกดจากมือถือ
- **slot 1 เป็น 🎲 สุ่มทั้งคลังเสมอ** ตั้งปุ่มได้แต่เปลี่ยนเป็นเสียงอื่นไม่ได้ (ไม่สุ่มซ้ำตัวเดิมติดกัน)
- ปุ่ม **＋ เพิ่ม slot** ท้ายรายการ
- อัปเกรดจากเวอร์ชันก่อน 1.3.0: คีย์ลัดเดิมถูกย้ายเข้า slot ให้เอง เรียงตามเลขปุ่ม

**หน้าเลือกเสียง**

- **กดชื่อเสียงเพื่อเลือก กดซ้ำเพื่อเอาออก** — เลือกกี่เสียงก็ได้ เสียงที่เลือกมี ✓ และกรอบสี
  (โหมดเรียงตามลำดับจะขึ้นเลข 1. 2. 3. ตามลำดับที่กด) · บันทึกทันทีทุกครั้งที่กด
- ปุ่ม **🎲 สุ่ม / 🔁 เรียงตามลำดับ** กับ **ล้างที่เลือก** อยู่ด้านล่างหน้าต่าง
- ช่องค้นหา — กรองทันทีที่พิมพ์ (วางข้อความด้วยเมาส์ก็กรอง) กด **Enter** = เลือก/เอาออกอันแรก
- ตัวกรองแหล่งที่มา **ทั้งหมด / Dota / Myinstants / TiengDong / YouTube / ของฉัน** (ดูจากชื่อไฟล์ที่โปรแกรมตั้งตอนโหลด)
- ติ๊ก **ซ่อนที่อยู่ใน slot แล้ว** ให้เห็นแต่เสียงที่ยังว่าง (เสียงใน slot นี้ยังเห็นอยู่)
- ▶ ในหน้านี้ **ฟังทางหูฟังเท่านั้น ไม่เข้าเกม**
- แสดงทีละ 40 รายการ เพื่อให้เปิดไว (คลัง 600 เสียงเปิดใน ~0.8 วินาที) พิมพ์เพิ่มเพื่อกรอง

**แท็บ 📚 คลังเสียง**

- ไฟล์ในโฟลเดอร์ `sounds/` ถูก**สแกนเข้าคลังอัตโนมัติทุกครั้งที่เปิดโปรแกรม**
- ไฟล์ที่อยู่ที่อื่นใช้ปุ่ม **เพิ่มไฟล์** / **เพิ่มทั้งโฟลเดอร์**
- ปุ่ม **＋ slot** = ใส่เสียงนี้ลง slot ว่างแรก (ไม่มีช่องว่างจะสร้างใหม่ให้) เสียงที่อยู่ใน slot แล้วจะมีป้าย `slot 3`
- **ดับเบิลคลิกที่ชื่อ** = เปลี่ยนชื่อ, **✕** = ลบออกจากคลัง (เสียงนั้นถูกดึงออกจากทุก slot ที่ใช้อยู่ ปุ่มยังอยู่)
- ช่อง **ค้นหาเสียง** ใช้ได้ทั้งสองแท็บ
- เมนูข้างช่องค้นหา = **การเรียงลำดับ**: **ใหม่ล่าสุด** (ค่าเริ่มต้น — เสียงที่เพิ่งเพิ่มอยู่บนสุด) · **เก่าสุด** · **ชื่อ ก-ฮ**
  ใช้กับคลังเสียง หน้าเลือกเสียงของ slot และรายการในมือถือ · เสียงที่มีอยู่ก่อน 1.14.0 ใช้วันที่ของไฟล์แทนวันที่เพิ่ม

**สวิตช์**

| สวิตช์ | ทำอะไร |
|---|---|
| ฟังเสียงตัวเอง | ได้ยินเสียงไมค์ตัวเองในหูฟัง (อยู่แถวมิเตอร์ไมค์) — ใช้หูฟังเท่านั้น ลำโพงจะหอน |
| เล่นทีละเสียง | เปิด = กดเสียงใหม่ตัดเสียงเก่า / ปิด = เล่นซ้อนกันได้ |
| ฮอตคีย์ | ปิดคีย์ลัดชั่วคราวตอนไม่ได้เล่นเกม |
| ปิดไมค์ | mute ไมค์จริง เหลือแต่ soundboard |
| ย่อลง tray | กดปิดหน้าต่าง = ซ่อนลง system tray ไม่ใช่ออกจากโปรแกรม |

## 🎚 ปรับเสียงไมค์

ปุ่ม **🎚 ปรับเสียงไมค์** แถวเดียวกับมิเตอร์ไมค์ — ทำกับไมค์จริงก่อนส่งเข้าเกม เปลี่ยนแล้วมีผลทันที

| สวิตช์ | ทำอะไร | ค่าใช้จ่าย |
|---|---|---|
| **ตัดเสียงรบกวน (AI)** | ตัดพัดลม แอร์ คีย์บอร์ด เสียงรอบห้อง เหลือแต่เสียงพูด ([RNNoise](https://github.com/xiph/rnnoise)) | แรม +~12 MB เฉพาะตอนเปิด · หน่วง ~20 ms · CPU ~5% ของ 1 คอร์ |
| **ตัดไมค์ตอนไม่ได้พูด** | ไมค์เงียบสนิทระหว่างไม่พูด — ใช้ AI ดูว่าเป็นเสียงคน (ไม่ใช่แค่ความดัง) เสียงคีย์บอร์ด/ประตูเลยไม่ทำให้ไมค์เปิด · ปรับ**ความไว**ได้ · ค้างเปิด 250 ms หลังพูดจบ ท้ายคำไม่ขาด | ใช้ AI ตัวเดียวกัน |
| **ปรับความดังอัตโนมัติ** | พูดเบาดังขึ้น (สูงสุด +18 dB) ตะโกนเบาลง มีตัวกันเสียงแตก · ปรับเฉพาะตอนพูด ไม่ดันเสียงรบกวนขึ้น | แทบไม่มี |
| **ตัดเสียงสะท้อนจากลำโพง** | ใช้ลำโพงแทนหูฟัง — อ่านเสียงที่ลำโพงเล่นอยู่ (WASAPI loopback) แล้วลบออกจากไมค์ด้วย WebRTC AEC3 · เลือกลำโพงเองได้ (ไม่มี CABLE ในรายการ เพราะในนั้นมีเสียงไมค์เราเอง) | แรม +~20 MB ตั้งแต่เปิดครั้งแรกจนปิดโปรแกรม · CPU ~1% |

- มีมิเตอร์ **เสียงจากไมค์** เทียบกับ **เพื่อนได้ยิน** และไฟ **● กำลังพูด** · เปิด **ฟังเสียงตัวเอง** เพื่อลองฟังผลได้ในหน้าเดียวกัน
- ปิดสวิตช์ AI ทั้งสองแล้ว โปรแกรมปลดตัว AI ออกจากแรมทันที (ไมค์สะดุด ~0.1 วินาทีตอนสลับ)
- เปิด**ตัดเสียงสะท้อน**คู่กับ**ตัดเสียงรบกวน** โปรแกรมจะใช้ตัวตัดเสียงรบกวนของ WebRTC แทน RNNoise —

## 🗣 พิมพ์ข้อความให้อ่าน (เสียงโดเนท)

ปุ่ม **🗣 พิมพ์ให้อ่าน** แถวล่าง — พิมพ์ข้อความ ได้ไฟล์เสียง **"เสียงแจ้งเตือน + เสียงอ่าน"** เก็บไว้ในคลัง เล่นซ้ำจากปุ่มลัดได้ตลอด

## 🤝 แชร์เสียงกับเพื่อน

ปุ่ม **🤝 แชร์เสียง** แถวล่าง — เก็บเสียงไว้ใน **repo ส่วนตัวของคุณเองบน GitHub** (โปรแกรมสร้างให้ ชื่อ `soundsaoter-sounds`) แล้วส่ง**รหัสชุดเสียง**ให้เพื่อน

**ฝั่งคนแชร์ (แท็บ ⬆ เสียงของฉัน)**

1. กด **วิธีสร้าง** → GitHub เปิดหน้าสร้าง token: Repository access = All repositories · Permissions → Repository → **Contents = Read and write** → Generate
2. วาง token แล้วกด **เชื่อมต่อ** (ครั้งเดียว — เก็บไว้ใน Windows Credential Manager ไม่ได้เก็บใน `config.json`)
3. กด **⬆** ข้างเสียงที่อยากแชร์ (หรือ **อัปที่ยังไม่ได้อัป** รวดเดียว) — เสียงที่เคยอัปแล้วจะข้ามให้ ไม่อัปซ้ำ
4. ก๊อป **รหัสให้เพื่อน** (ขึ้นต้น `SST1-`) ส่งทาง Discord

**ฝั่งเพื่อน (แท็บ ⬇ เสียงของเพื่อน)** — วางรหัส → **ดูรายการเสียง** → กด **⬇** ทีละเสียง หรือ **โหลดที่ยังไม่มีทั้งหมด** · ไฟล์ลงโฟลเดอร์ `sounds/` และเข้าคลังให้เลย

| เรื่อง | รายละเอียด |
|---|---|
| ทำไมต้อง repo **ส่วนตัว** | เสียงส่วนใหญ่เป็นของเจ้าของลิขสิทธิ์ (Dota, YouTube, คลิปมีม) เก็บไว้ในวงเพื่อนได้ แต่ไม่ควรเปิดสาธารณะ |
| รหัสชุดเสียง | ข้างในมีชื่อ repo กับ token — **ใครได้รหัสนี้เข้าถึง repo เสียงของคุณได้** ส่งเฉพาะคนที่ไว้ใจ ถ้าหลุดให้ลบ token ทิ้งที่ GitHub |
| ไม่โหลดซ้ำ | เทียบด้วย sha256 ทั้งขาอัปและขาโหลด ไฟล์ที่มีอยู่แล้วข้ามทันที และเช็กว่าไฟล์ที่โหลดมาครบถ้วน |
| ชื่อไฟล์บน GitHub | เป็นรหัส sha256 12 ตัวแรก (ไม่ใช่ชื่อไทย) ส่วนชื่อที่คนอ่านอยู่ใน `index.json` |
| ขนาด | จำกัดไฟล์ละ 40 MB |

> โค้ดอยู่ที่ [soundshare.py](soundshare.py) — ใช้ GitHub Releases เก็บไฟล์ (เหมือนที่ระบบอัปเดตใช้) และ `urllib` ล้วน ไม่มีไลบรารีเพิ่ม

## 📱 ใช้มือถือกดเสียง

ปุ่ม **📱 มือถือ** แถวเครื่องมือ → เปิดสวิตช์ → สแกน QR ด้วยกล้องมือถือ (Wi-Fi วงเดียวกับคอม ไม่ต้องลงแอป)

## ตั้งค่า (ปุ่ม ⚙ มุมขวาล่าง)

> **ส่งเสียงเต็ม 100%** (เปิดไว้เป็นค่าเริ่มต้นตั้งแต่ 1.15.0) — ไฟล์ถูกส่งออก**ตรงตามต้นฉบับ**
> ปิดสวิตช์นี้ถึงจะกลับไปใช้ "ตัดช่วงเงียบหัวท้าย" (ตัดส่วนที่เบากว่าเสียงดังสุด 45 dB — บางไฟล์โดนตัดเกือบ 1 วินาที)
> และ "ปรับทุกเสียงให้ดังพอ ๆ กัน" (หรี่เสียงที่ดังเกิน — บางไฟล์เหลือ 0.42 เท่า)


| ตัวเลือก | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| สีธีม | ม่วงนีออน | เลือกสี (โหมดมืด/สว่างสลับที่ปุ่มขวาบน) |
| ตัดช่วงเงียบหัวท้าย | เปิด | ตัดความเงียบต้นและท้ายคลิป กดคีย์ลัดแล้วเสียงออกทันที |
| ปรับทุกเสียงให้ดังพอ ๆ กัน | เปิด | คลิปเบาถูกดันขึ้น คลิปดังถูกกดลง (ดันได้ไม่เกิน 6 เท่า และไม่ให้แตก) |
| กันสแปม | 2 วิ | เว้นระยะขั้นต่ำระหว่างเสียงที่กดจาก**คีย์ลัด** กดในหน้าต่างเองไม่ถูกจำกัด |
| เปิดพร้อม Windows | ปิด | เปิดเครื่องแล้วไปรอใน tray เลย (ใช้ได้เฉพาะ exe) |
| หน่วยความจำ | 40 MB | ดูว่าเสียงกินแรมเท่าไหร่ และล้างได้ |

การตัดเงียบกับการปรับความดังทำ**ครั้งเดียวตอนโหลดไฟล์** ตอนเล่นไม่ต้องคำนวณเพิ่ม ไฟล์ต้นฉบับบนดิสก์ไม่ถูกแก้

### ดังเบาแยกแต่ละเสียง

ปุ่ม **🔊 100%** ในแต่ละแถว — กดเพื่อเปิดสไลเดอร์ (0-200%) หรือเลื่อนล้อเมาส์บนปุ่มเพื่อปรับทีละ 5%
ค่านี้คูณกับสไลเดอร์ "เสียงเข้าเกม" อีกชั้น

### แรม

เสียงที่ถอดรหัสแล้วเก็บไว้ในแรมได้ไม่เกินเพดาน (ค่าเริ่มต้น 40 MB) เกินแล้วเสียงที่ไม่ได้ใช้นานสุดจะถูกคืนก่อน
ไม่ว่าจะมีเสียงกี่ร้อยไฟล์ แรมก็ไม่เกินเพดานนี้ (เวอร์ชันก่อน 1.2.0 เก็บทุกเสียงค้างไว้ไม่คืน)

## รันบนพื้นหลัง

เปิดสวิตช์ **ย่อลง tray** ไว้ (ค่าเริ่มต้น) แล้วกดปิดหน้าต่าง — โปรแกรมจะซ่อนลง system tray
ยังทำงานอยู่ ฮอตคีย์ยังใช้ได้ตามปกติ

คลิกขวาที่ไอคอนใน tray จะได้เมนู:

| เมนู | ทำอะไร |
|---|---|
| **เปิดหน้าต่าง** (ดับเบิลคลิกไอคอนก็ได้) | เรียกหน้าต่างกลับมา |
| **ฮอตคีย์** | เปิด/ปิดคีย์ลัด มีเครื่องหมายถูกบอกสถานะ |
| **หยุดเสียง** | หยุดเสียงที่กำลังเล่น |
| **ออกจากโปรแกรม** | ปิดจริง คืนปุ่มให้ระบบ |

ถ้าปิดสวิตช์นี้ กดปิดหน้าต่าง = ออกจากโปรแกรมเลยแบบเดิม

ป้าย **ctrl+alt+s** ข้างปุ่มหยุดเสียง = ปุ่มหยุดฉุกเฉิน กดที่ป้ายเพื่อเปลี่ยน

ค่าทั้งหมดถูกบันทึกลง `config.json` อัตโนมัติ

### ระบบฮอตคีย์

ใช้ **`RegisterHotKey` ของ Windows** ([hotkeys.py](hotkeys.py)) ไม่ใช่ global keyboard hook

- โปรแกรมเห็นเฉพาะปุ่มที่ลงทะเบียนไว้เท่านั้น ปุ่มอื่นที่พิมพ์ไม่ถูกอ่านเลย
- ไม่ยิง input ปลอมเข้าเกม ไม่ inject อะไรทั้งสิ้น → ไม่เข้าข่ายพฤติกรรมที่ anti-cheat จับ
- ไม่ต้อง Run as administrator
- ไม่ต้องลงไลบรารีเพิ่ม (เรียก Win32 ผ่าน ctypes)

**ข้อแลกเปลี่ยน:** ปุ่มที่ลงทะเบียนจะถูก Windows กินไว้ ไม่ส่งต่อให้เกม
เพราะฉะนั้น **ห้ามใช้ปุ่มที่ต้องกดในเกม**

### เลือกปุ่มยังไงไม่ให้ชนกับเกม

Dota 2 ใช้ F1–F12, Q W E R, ตัวเลข 1–9 หมด แนะนำ:
- ปุ่ม numpad: `num 1`, `num 2`, ...
- หรือคอมโบ: `ctrl+alt+1`, `alt+z`

ถ้าโปรแกรมอื่นจองปุ่มนั้นไว้แล้ว (Discord, GeForce Experience ฯลฯ) แถบสถานะจะขึ้นว่า
"ปุ่มถูกโปรแกรมอื่นจองอยู่" ให้เปลี่ยนปุ่ม

## หาไฟล์เสียง

กดปุ่ม **⭳ โหลดเสียงจากเว็บ** ในโปรแกรม แล้วเลือกเว็บจากปุ่มสลับด้านบน

แต่ละแถวผลลัพธ์มี 2 ปุ่ม:

- **▶** — ฟังตัวอย่างก่อน **ออกทางหูฟังเท่านั้น ไม่เข้าเกม** (ไฟล์พักไว้ที่โฟลเดอร์ temp)
- **⭳ โหลด** — บันทึกลง `sounds/` แล้วเพิ่มเข้ารายการให้อัตโนมัติ

ระหว่างโหลดจะมี**หลอดความคืบหน้า**ขึ้นมุมขวาล่างของหน้าต่าง ไฟล์เขียนเป็น `.part` ก่อน
แล้วค่อยเปลี่ยนชื่อตอนเสร็จ จะได้ไม่มีไฟล์โหลดค้างครึ่ง ๆ อยู่ในรายการ

> ปุ่ม ▶ จะเลี่ยง virtual cable เสมอ ต่อให้ Windows ตั้ง CABLE เป็นลำโพงเริ่มต้นไว้
> เสียงตัวอย่างก็จะไม่หลุดเข้าเกม

| เว็บ | ค้นด้วยอะไร | ได้อะไร |
|---|---|---|
| **Dota 2** ([dota2voicelines.com](https://dota2voicelines.com/)) | ชื่อคนพากย์ ข้อความ หรือ ID เช่น `401945` | เสียง chat wheel ~2,000 รายการ |
| **Myinstants** ([myinstants.com](https://www.myinstants.com/)) | คำค้นอะไรก็ได้ หรือ**วางลิงก์หน้าไหนก็ได้ของเว็บ** | sound effect / meme ทั่วไป |
| **TiengDong** ([tiengdong.com/th](https://tiengdong.com/th/)) | เลือก**หมวด** แล้วพิมพ์กรอง · วางลิงก์หน้าเสียง · 🌐 เปิดค้นในเบราว์เซอร์ | มีมไทย น้าค่อม เสียงหัวเราะ เอฟเฟกต์ ฯลฯ (ชื่อเสียงภาษาไทย) |

การวางลิงก์มีประโยชน์ตรงที่เปิดหน้า category หรือ trending ในเบราว์เซอร์แล้วก๊อปมาวาง

`https://www.myinstants.com/en/categories/sound%20effects/us/` → 36 เสียง

### ทำไม TiengDong ต้องเลือกหมวด ไม่ค้นตรง ๆ

robots.txt ของ tiengdong.com **ห้ามโปรแกรมใช้หน้าค้นหาของเว็บ** (`Disallow: */th/?s=*`) และหน้าถัดไปของหน้าแรก (`*/th/page/*`)
โปรแกรมนี้เคารพกฎนั้น เลยอ่านเฉพาะหน้าที่เว็บอนุญาต คือหน้าแรก หน้าหมวด และหน้าเสียงแต่ละตัว แล้ว**กรองชื่อในเครื่องเอง**

- เลือกหมวด (หน้าแรก, เสียงมีมไทย, เสียงน้าค่อม, เสียงแนวโน้ม, เสียงหัวเราะ, เอฟเฟกต์ streamer, ปืน, สยองขวัญ ฯลฯ 17 หมวด) → โหลด 3 หน้าแรกของหมวด
- พิมพ์กรองได้ทันที ไม่ต้องใส่วรรณยุกต์ (`คอม` เจอ `น้าค่อม`) และไม่ยิงเว็บซ้ำ
- หน้ารายการของเว็บไม่มีลิงก์ไฟล์เสียง ตอนกด ▶ ฟัง หรือโหลด โปรแกรมจะเปิดหน้าของเสียงนั้น 1 ครั้งเพื่อหาไฟล์
- **🌐** เปิดหน้าค้นหาของเว็บในเบราว์เซอร์ให้คุณค้นเอง เจอแล้วก๊อปลิงก์หน้าเสียงมาวางในช่อง
- วางลิงก์หน้าค้นหาจะถูกปฏิเสธ (เป็นหน้าที่เว็บห้าม)
- อ่าน robots.txt ก่อนเปิดทุกหน้า (ตีความ `*` แบบ Google ซึ่ง `urllib.robotparser` ทำไม่ได้), เว้นจังหวะ 0.6 วินาทีระหว่างหน้า และจำหน้าที่โหลดแล้ว

### จากบรรทัดคำสั่ง

[download_voice.py](download_voice.py) ทำแบบเดียวกันได้:

```
python download_voice.py 401945                        โหลดเสียง Dota ตาม ID
python download_voice.py --find Ams                    ค้นในเว็บ Dota
python download_voice.py --site myinstants --find rampage
python download_voice.py --site myinstants --get "https://www.myinstants.com/en/instant/dota-rampage/"
```

ชื่อไฟล์: Dota = `<ID> - <คนพากย์> - <ข้อความ>.mp3` · Myinstants = `<ชื่อ> [<ID>].mp3` · TiengDong = `<ชื่อ> [td<ID>].mp3` · YouTube = `<ชื่อ> [yt<คลิป>-<มิลลิวินาทีที่เริ่ม>].mp3`

> ตัวเชื่อมเว็บอยู่ใน [sources.py](sources.py) เพิ่มเว็บใหม่ได้โดยเขียนคลาสที่มี `search()` แล้วใส่ใน `SOURCES`
> เว็บ Dota อ่านจาก `src/voice_lines_list.html` เพราะหน้าแรกอยู่หลัง Cloudflare ดึงตรง ๆ ไม่ได้

## ✂ ตัดเสียงจาก YouTube

ปุ่ม **✂ ตัดจาก YouTube** แถวล่าง → วางลิงก์คลิป → **เปิดคลิป**
(ลิงก์ที่แชร์แบบ "เริ่มที่เวลา…" ซึ่งมี `&t=` จะเปิดตรงนั้นเลย)

| ส่วน | ใช้ยังไง |
|---|---|
| แถบ **ทั้งคลิป** | ความดังตลอดคลิป กรอบชมพู = ช่วงที่โหลดอยู่ · **คลิกตรงไหนก็ได้เพื่อกระโดดไปช่วงนั้น** |
| **โหลดทีละ 15 / 30 / 60 วิ** | ขนาดช่วงที่ดึงมาแก้ · **◀ ช่วงก่อน / ช่วงถัดไป ▶** เลื่อนทีละ ¾ ช่วง |
| ภาพ **ความถี่** / **คลื่นเสียง** | ความถี่ = สเปกโตรแกรม (ล่าง = เสียงทุ้ม, บน = เสียงแหลม, สว่าง = ดัง) เห็นจุดเริ่มคำพูด/เสียงกลองชัดกว่าคลื่นเสียง |
| **ลากบนภาพ** | เลือกช่วง · **ลากเส้นชมพู** ปรับขอบ |
| **ล้อเมาส์** | ซูมเข้า-ออกรอบเมาส์ ซูมได้ถึงช่วงกว้าง 0.02 วินาที · **คลิกขวาลาก** หรือ **Shift+ล้อ** เลื่อนซ้าย-ขวา |
| ช่อง **เริ่ม / จบ** | พิมพ์เวลาเองได้ (`1:23.456` หรือ `83.456`) · ปุ่ม **− / +** ขยับทีละ 10 ms · พิมพ์เวลานอกช่วงที่โหลด มันจะโหลดช่วงนั้นมาให้ |
| **▶ ฟังช่วงที่เลือก** (หรือ Space) | ฟังทางหูฟัง **ไม่เข้าเกม** มีเส้นเขียววิ่งบอกตำแหน่ง |
| **บันทึกลงคลังเสียง** | เป็น mp3 ใน `sounds/` ใส่ fade 6 ms หัวท้ายกันเสียงคลิก แล้วเข้ารายการทันที · ตัวกรอง **YouTube** ในหน้าเลือกเสียงของ slot |

### ทำไมไม่กินแรม

- yt-dlp กับ ffmpeg (PyAV) **ไม่เคยโหลดเข้าโปรแกรมหลัก** — ทุกงาน (เปิดคลิป, โหลดช่วง, ภาพรวม)
  รันในโปรเซสลูก (`SoundSaoTer.exe --yt-worker`) ที่ทำเสร็จแล้วปิดตัวทันที แรมคืน Windows หมด
  (โปรเซสลูกใช้ราว 40–80 MB อยู่ไม่กี่วินาที)
- ffmpeg **กระโดดไปวินาทีที่ต้องการแล้วถอดเฉพาะช่วงนั้น** — ช่วง 30 วิดึงข้อมูลแค่ราว 0.5 MB ไม่โหลดทั้งคลิป
- แถบภาพรวมทั้งคลิปอ่านแบบไหลผ่านที่ 8 kHz เก็บแค่ความดัง 1,200 จุด (คลิปยาวเกิน 20 นาทีข้ามไป)
- โปรแกรมหลักถือแค่ช่วงที่โหลด (mono 48 kHz, 30 วิ ≈ 5.8 MB) ปิดหน้าต่างแล้วทิ้งหมด
- ตอนไม่เปิดหน้าต่างนี้ แรมเท่าเดิม (ว่าง ๆ ~73 MB เทียบกับ 1.5.1 ที่ ~70 MB) แต่ไฟล์ exe ใหญ่ขึ้นเป็น ~56 MB เพราะรวม ffmpeg ไว้ในตัว

> ข้อตกลงของ YouTube ไม่อนุญาตให้ดาวน์โหลดคลิป และเสียงในคลิปเป็นลิขสิทธิ์ของเจ้าของ
> ตัดคลิปสั้น ๆ ไว้ใช้เองในเกม ไม่ควรเอาไปเผยแพร่ต่อ
>
> YouTube เปลี่ยนระบบบ่อย ถ้าวันหนึ่งเปิดคลิปไม่ได้ทั้งที่ลิงก์ถูก แปลว่า yt-dlp ตามไม่ทัน —
> อัปเดต yt-dlp (`.venv\Scripts\python -m pip install -U yt-dlp`) แล้ว build ออกเวอร์ชันใหม่

## ปัญหาที่เจอบ่อย

| อาการ | แก้ |
|---|---|
| มีไฟล์ใน `sounds/` แต่หน้าโปรแกรมว่าง | โปรแกรมแสดงรายการจาก `config.json` ไม่ใช่จากโฟลเดอร์ — เวอร์ชันใหม่สแกนให้ตอนเปิดแล้ว ถ้ายังว่างให้กด "เพิ่มทั้งโฟลเดอร์" |
| เช็คว่ามองโฟลเดอร์ไหนอยู่ | โปรแกรมใช้ `sounds/` ที่อยู่**ข้างตัว exe** เสมอ — ถ้ารันจาก `dist/SoundSaoTer.exe` ก็คือ `dist/sounds/` ไม่ใช่โฟลเดอร์ source |
| ไม่เห็น CABLE ในรายการ | ยังไม่ได้รีสตาร์ตหลังติดตั้ง VB-CABLE / กด "รีเฟรชอุปกรณ์" |
| เห็น `CABLE Input` แต่เลือกแล้ว error | บางเครื่อง Windows ทิ้งรายการผีไว้ ตัวที่ใช้ได้จริงคือ `CABLE In 16ch` — โปรแกรมทดลองเปิดจริงก่อนเลือกให้อยู่แล้ว |
| ฮอตคีย์ถูกจองทั้งที่ไม่มีโปรแกรมอื่น | มี soundboard อีกหน้าต่างเปิดค้างอยู่ ปิดตัวเก่าก่อน |
| ฮอตคีย์ไม่ทำงาน | ปุ่มชนกับโปรแกรมอื่น — ดูแถบสถานะแล้วเปลี่ยนปุ่ม (ไม่ต้องใช้ admin) |
| กดปุ่มนั้นในเกมแล้วเกมไม่ตอบสนอง | ปกติ — Windows กินปุ่มที่ลงทะเบียนไว้ ให้เลือกปุ่มที่ไม่ได้ใช้ในเกม |
| คนอื่นได้ยินเบามาก | เพิ่ม Levels ของ CABLE Output ใน Windows + เพิ่มสไลเดอร์ "เสียงเข้าเกม" |
| เสียงแตก | ลดสไลเดอร์ลงต่ำกว่า 100% |
| พูดแล้วคนอื่นไม่ได้ยิน | ยังไม่ได้เลือก "ไมค์จริง (ส่งเข้าเกมด้วย)" ในโปรแกรม |
| เสียงพูดสะท้อน/หอน | เลือก CABLE Output เป็นไมค์จริงอยู่ ให้เปลี่ยนเป็นไมค์ตัวจริง |
| เปิดอุปกรณ์ไม่ได้ (error) | ลองเลือกอุปกรณ์ตัวเดียวกันแต่เป็น `[MME]` หรือ `[Windows DirectSound]` แทน WASAPI |

## ข้อควรรู้เรื่อง anti-cheat

โปรแกรมนี้ไม่แตะตัวเกมเลย — ไม่อ่าน/เขียน memory, ไม่ inject DLL, ไม่ hook DirectX,
ไม่ส่ง input ปลอม มันเป็นแค่โปรแกรมเล่นไฟล์เสียง ระดับเดียวกับ Discord หรือ OBS

ฮอตคีย์ใช้ `RegisterHotKey` ซึ่งเป็น API ที่เปิดเผยของ Windows ไม่ใช่ low-level hook
แบบที่โปรแกรม macro ใช้ และ VB-CABLE ก็เป็น signed driver ที่สตรีมเมอร์ใช้กันทั่วโลก

ความเสี่ยงจริงไม่ใช่ anti-cheat แต่เป็น **ระบบรีพอร์ต** — สแปมเสียงใส่ voice chat
เข้าข่าย harassment โดนรีพอร์ตเยอะ ๆ ก็โดน voice ban ได้ ใช้พอประมาณ
