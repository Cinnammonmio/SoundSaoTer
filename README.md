# SoundSaoTer — ส่งไฟล์เสียงเข้าไมค์ในเกม

กดคีย์ลัด → ไฟล์เสียงในเครื่องถูกส่งออกเป็น "ไมค์" ให้คนอื่นในเกม (Dota 2, Discord, ฯลฯ) ได้ยิน

## ทำไมต้องมี Virtual Cable

Windows ไม่เปิดให้โปรแกรมใด ๆ ยัดเสียงเข้าไมค์จริงได้ ต้องสร้าง "ไมค์ปลอม" ขึ้นมาก่อน
โปรแกรมนี้เล่นเสียงออก **CABLE Input** แล้วเกมรับเสียงจาก **CABLE Output** เหมือนเป็นไมค์ตัวหนึ่ง

```
ไฟล์ mp3 ─┐
          ├→ soundboard.py → CABLE Input (ลำโพงปลอม) ══ CABLE Output (ไมค์ปลอม) → Dota 2
ไมค์จริง ─┘                └→ หูฟังของเรา (monitor, จะเปิดหรือไม่ก็ได้)
```

โปรแกรมผสม **ไมค์จริง + ไฟล์เสียง** เข้า cable เส้นเดียวกัน เลยยังพูดคุยได้ปกติ

## ติดตั้ง

1. **VB-CABLE** — แนบไว้ให้แล้วใน [vbcable/](vbcable/) (ไฟล์ต้นฉบับจาก https://www.vb-cable.com)
   แตกไฟล์ → คลิกขวา `VBCABLE_Setup_x64.exe` → **Run as administrator** → Install Driver → **รีสตาร์ตเครื่อง**
   VB-CABLE เป็น donationware ของ VB-Audio ไม่ใช่ของโปรเจกต์นี้ — ถ้าชอบช่วยสนับสนุนผู้พัฒนาได้
2. ไลบรารี Python (ติดตั้งไว้ให้แล้วในเครื่องนี้):
   ```
   pip install -r requirements.txt
   ```

โหลด `SoundSaoTer.exe` ไฟล์เดียว ไม่ต้องมี Python

## อัปเดตอัตโนมัติ

โปรแกรมตรวจหาเวอร์ชันใหม่ให้เองตอนเปิด (หลังเปิด 2.5 วินาที) ถ้ามีของใหม่
ปุ่มมุมขวาบนจะเปลี่ยนเป็นสีชมพู **"อัปเดต vX.Y.Z"** พร้อมแจ้งเตือนที่ tray

กดแล้วมันจะโหลด → ตรวจ sha256 → สลับตัวเอง → เปิดใหม่ให้ ไม่ต้องไปโหลดเองอีก

### ออกเวอร์ชันใหม่ยังไง

```
1. แก้ VERSION กับ CHANGES ใน version.py
2. python build.py
3. python publish.py
```

`publish.py` จะสร้าง GitHub release ตามเลขเวอร์ชัน อัป exe ขึ้นไป แล้วเขียน `latest.json`
ที่ทุกเครื่องใช้ตรวจอัปเดต — เพื่อนที่ถือเวอร์ชันเก่าจะเห็นปุ่มอัปเดตเด้งเองในการเปิดครั้งถัดไป

| ไฟล์ | หน้าที่ |
|---|---|
| [version.py](version.py) | เลขเวอร์ชัน, รายการที่เปลี่ยน, ที่อยู่ไฟล์ประกาศ |
| [updater.py](updater.py) | ตรวจ/โหลด/สลับตัวเอง พร้อมตรวจ sha256 ก่อนติดตั้ง |
| [publish.py](publish.py) | อัปขึ้น GitHub Releases |

ถ้าโหลดมาแล้วลายนิ้วมือไม่ตรง หรือไฟล์เล็กผิดปกติ โปรแกรมจะไม่ติดตั้งและเก็บตัวเดิมไว้
การสลับไฟล์ใช้วิธีเปลี่ยนชื่อตัวเก่าเป็น `.old` (Windows ห้ามเขียนทับ exe ที่กำลังรัน แต่ยอมให้เปลี่ยนชื่อ)
ถ้าย้ายตัวใหม่เข้าที่ไม่สำเร็จจะย้อนตัวเก่ากลับมาให้อัตโนมัติ

## สร้าง .exe ส่งให้เพื่อน

```
python build.py
```

ได้ **`dist/SoundSaoTer.exe`** (~25 MB) ไฟล์เดียวจบ เพื่อนไม่ต้องมี Python
สคริปต์จะเตรียมโฟลเดอร์ `dist/ส่งให้เพื่อน/` ที่มี exe + [อ่านก่อนใช้.txt](อ่านก่อนใช้.txt) + ตัวติดตั้ง VB-CABLE + โฟลเดอร์ `sounds/` ให้พร้อมซิปส่งเลย

- `config.json` กับ `sounds/` จะถูกสร้างข้าง ๆ ตัว exe → ย้ายโฟลเดอร์ไปไหนก็พกค่าไปด้วย
- ไฟล์ไม่ได้เซ็น certificate ครั้งแรกจะโดน SmartScreen เตือน → **More info → Run anyway**
- เปลี่ยนไอคอนได้ที่ [make_icon.py](make_icon.py) แล้วรัน `python make_icon.py`

## ตั้งค่าเสียงใน Windows

- **Sound → Recording → CABLE Output** → คลิกขวา → Properties → แท็บ **Listen**
  ถ้าติ๊ก "Listen to this device" จะได้ยินเสียงตัวเองด้วย (หรือใช้ช่อง "ฟังเองที่หูฟัง" ในโปรแกรมแทนก็ได้ — แนะนำอันนี้มากกว่า เพราะไม่ทำให้เสียงดีเลย์)
- **CABLE Output → Levels** ตั้งไว้ประมาณ 70–100

## ตั้งค่าใน Dota 2

Settings → Audio → **Voice / Microphone Device** → เลือก `CABLE Output (VB-Audio Virtual Cable)`
แล้วใช้ปุ่ม push-to-talk ตามปกติ: กด push-to-talk ค้างไว้ แล้วกดคีย์ลัดของ soundboard

## ยังพูดเองได้ไหม

ได้ — แต่ **ต้องตั้งช่อง "ไมค์จริง (ส่งเข้าเกมด้วย)" ในโปรแกรมก่อน**

พอเปลี่ยนไมค์ในเกมเป็น CABLE Output แล้ว เกมจะได้ยินเฉพาะสิ่งที่ส่งเข้า CABLE Input เท่านั้น
ไมค์จริง (Yeti GX ฯลฯ) จะเงียบไปเลย ถ้าไม่ได้ส่งต่อเข้า cable

โปรแกรมนี้อ่านไมค์จริงแล้วผสมเข้า CABLE Input ให้ เลยได้ทั้งเสียงพูดและ soundboard พร้อมกัน
แถบระดับเสียงข้าง ๆ จะขยับตามเสียงพูด ใช้เช็คได้ว่าไมค์เข้าจริง

- ดีเลย์เสียงพูดที่เพิ่มขึ้นประมาณ 20–60 ms (คนอื่นแทบไม่รู้สึก)
- ติ๊ก **ปิดไมค์ชั่วคราว** = mute ไมค์จริง เหลือแต่ soundboard
- **อย่า** เลือก `CABLE Output` เป็นช่องไมค์จริง จะเกิด feedback loop

### ทางเลือกที่ไม่ต้องพึ่งโปรแกรมนี้

| วิธี | ข้อดี | ข้อเสีย |
|---|---|---|
| ช่อง "ไมค์จริง" ในโปรแกรม | ไม่ต้องลงอะไรเพิ่ม เปิด/ปิดง่าย | ต้องเปิดโปรแกรมค้างไว้ |
| Windows: Sound → Recording → **ไมค์จริง** → Properties → **Listen** → ติ๊ก Listen to this device → Playback through **CABLE Input** | Windows จัดการให้ ไม่ต้องเปิดโปรแกรม | ดีเลย์สูงกว่า, ลืมปิดแล้วงง |
| VoiceMeeter Banana | ดีเลย์ต่ำสุด ปรับ EQ/compressor ได้ | ต้องลง driver เพิ่ม เรียนรู้นาน |

## วิธีใช้

`run.bat` (จาก source) หรือ `dist/SoundSaoTer.exe`

**แถวอุปกรณ์ 3 ช่อง**

- 🎮 **เสียงเข้าเกม** → ตัว `CABLE ...` ที่เป็น WASAPI
  โปรแกรมเลือกให้อัตโนมัติตอนเปิดครั้งแรก โดย**ทดลองเปิดจริงก่อน** ไม่ได้เดาจากชื่อ
- 🎧 **ฟังเองที่หูฟัง** → หูฟังตัวเอง (เลือก `— ไม่ใช้ —` ถ้าไม่อยากได้ยิน)
- 🎤 **ไมค์จริง** → ไมค์ตัวจริง เพื่อให้ยังพูดคุยได้ตามปกติ
  แถบ **ระดับเสียงไมค์** ใต้ช่องจะขยับตามเสียงพูด ใช้เช็คว่าไมค์เข้าจริง

**รายการเสียง**

- ไฟล์ที่อยู่ในโฟลเดอร์ `sounds/` จะถูก**สแกนเข้ารายการอัตโนมัติทุกครั้งที่เปิดโปรแกรม**
  ก๊อปไฟล์ใส่โฟลเดอร์นั้นแล้วเปิดโปรแกรมใหม่ก็ขึ้นเอง (ฮอตคีย์ที่ตั้งไว้เดิมไม่หาย)
- ไฟล์ที่อยู่ที่อื่นต้องใช้ปุ่ม **เพิ่มไฟล์** / **เพิ่มทั้งโฟลเดอร์**

- ปุ่ม **▶** สีม่วงหน้าแต่ละแถว = เล่นทดสอบ (แถวนั้นจะกะพริบชมพู)
- ป้ายข้างขวา = ฮอตคีย์ **คลิกเพื่อตั้ง / คลิกขวาเพื่อล้าง**
- **ดับเบิลคลิกที่ชื่อ** = เปลี่ยนชื่อ, **✕** = ลบออกจากรายการ
- ช่อง **ค้นหาเสียง** ด้านบนไว้กรองตอนมีเสียงเยอะ

**สวิตช์**

| สวิตช์ | ทำอะไร |
|---|---|
| ฟังเสียงตัวเอง | ได้ยินเสียงไมค์ตัวเองในหูฟัง (อยู่แถวมิเตอร์ไมค์) — ใช้หูฟังเท่านั้น ลำโพงจะหอน |
| เล่นทีละเสียง | เปิด = กดเสียงใหม่ตัดเสียงเก่า / ปิด = เล่นซ้อนกันได้ |
| ฮอตคีย์ | ปิดคีย์ลัดชั่วคราวตอนไม่ได้เล่นเกม |
| ปิดไมค์ | mute ไมค์จริง เหลือแต่ soundboard |
| ย่อลง tray | กดปิดหน้าต่าง = ซ่อนลง system tray ไม่ใช่ออกจากโปรแกรม |

## รันบนพื้นหลัง

เปิดสวิตช์ **ย่อลง tray** ไว้ (ค่าเริ่มต้น) แล้วกดปิดหน้าต่าง — โปรแกรมจะซ่อนลง system tray
ยังทำงานอยู่ ฮอตคีย์ยังใช้ได้ตามปกติ

คลิกขวาที่ไอคอนใน tray จะได้เมนู:

| เมนู | ทำอะไร |
|---|---|
| **เปิดหน้าต่าง** (ดับเบิลคลิกไอคอนก็ได้) | เรียกหน้าต่างกลับมา |
| **ฮอตคีย์** | เปิด/ปิดคีย์ลัด มีเครื่องหมายถูกบอกสถานะ |
| **หยุดเสียง** | หยุดเสียงที่กำลังเล่น |
| **ออกจากโปรแกรม** | ปิดจริง คืนปุ่มให้ระบบ |

ถ้าปิดสวิตช์นี้ กดปิดหน้าต่าง = ออกจากโปรแกรมเลยแบบเดิม

ป้าย **ctrl+alt+s** ข้างปุ่มหยุดเสียง = ปุ่มหยุดฉุกเฉิน กดที่ป้ายเพื่อเปลี่ยน

ค่าทั้งหมดถูกบันทึกลง `config.json` อัตโนมัติ

### ระบบฮอตคีย์

ใช้ **`RegisterHotKey` ของ Windows** ([hotkeys.py](hotkeys.py)) ไม่ใช่ global keyboard hook

- โปรแกรมเห็นเฉพาะปุ่มที่ลงทะเบียนไว้เท่านั้น ปุ่มอื่นที่พิมพ์ไม่ถูกอ่านเลย
- ไม่ยิง input ปลอมเข้าเกม ไม่ inject อะไรทั้งสิ้น → ไม่เข้าข่ายพฤติกรรมที่ anti-cheat จับ
- ไม่ต้อง Run as administrator
- ไม่ต้องลงไลบรารีเพิ่ม (เรียก Win32 ผ่าน ctypes)

**ข้อแลกเปลี่ยน:** ปุ่มที่ลงทะเบียนจะถูก Windows กินไว้ ไม่ส่งต่อให้เกม
เพราะฉะนั้น **ห้ามใช้ปุ่มที่ต้องกดในเกม**

### เลือกปุ่มยังไงไม่ให้ชนกับเกม

Dota 2 ใช้ F1–F12, Q W E R, ตัวเลข 1–9 หมด แนะนำ:
- ปุ่ม numpad: `num 1`, `num 2`, ...
- หรือคอมโบ: `ctrl+alt+1`, `alt+z`

ถ้าโปรแกรมอื่นจองปุ่มนั้นไว้แล้ว (Discord, GeForce Experience ฯลฯ) แถบสถานะจะขึ้นว่า
"ปุ่มถูกโปรแกรมอื่นจองอยู่" ให้เปลี่ยนปุ่ม

## หาไฟล์เสียง

กดปุ่ม **⭳ โหลดเสียงจากเว็บ** ในโปรแกรม แล้วเลือกเว็บจากปุ่มสลับด้านบน

แต่ละแถวผลลัพธ์มี 2 ปุ่ม:

- **▶** — ฟังตัวอย่างก่อน **ออกทางหูฟังเท่านั้น ไม่เข้าเกม** (ไฟล์พักไว้ที่โฟลเดอร์ temp)
- **⭳ โหลด** — บันทึกลง `sounds/` แล้วเพิ่มเข้ารายการให้อัตโนมัติ

ระหว่างโหลดจะมี**หลอดความคืบหน้า**ขึ้นมุมขวาล่างของหน้าต่าง ไฟล์เขียนเป็น `.part` ก่อน
แล้วค่อยเปลี่ยนชื่อตอนเสร็จ จะได้ไม่มีไฟล์โหลดค้างครึ่ง ๆ อยู่ในรายการ

> ปุ่ม ▶ จะเลี่ยง virtual cable เสมอ ต่อให้ Windows ตั้ง CABLE เป็นลำโพงเริ่มต้นไว้
> เสียงตัวอย่างก็จะไม่หลุดเข้าเกม

| เว็บ | ค้นด้วยอะไร | ได้อะไร |
|---|---|---|
| **Dota 2** ([dota2voicelines.com](https://dota2voicelines.com/)) | ชื่อคนพากย์ ข้อความ หรือ ID เช่น `401945` | เสียง chat wheel ~2,000 รายการ |
| **Myinstants** ([myinstants.com](https://www.myinstants.com/)) | คำค้นอะไรก็ได้ หรือ**วางลิงก์หน้าไหนก็ได้ของเว็บ** | sound effect / meme ทั่วไป |

การวางลิงก์มีประโยชน์ตรงที่เปิดหน้า category หรือ trending ในเบราว์เซอร์แล้วก๊อปมาวาง
จะได้ทั้งหน้ามาเลย เช่น
`https://www.myinstants.com/en/categories/sound%20effects/us/` → 36 เสียง

### จากบรรทัดคำสั่ง

[download_voice.py](download_voice.py) ทำแบบเดียวกันได้:

```
python download_voice.py 401945                        โหลดเสียง Dota ตาม ID
python download_voice.py --find Ams                    ค้นในเว็บ Dota
python download_voice.py --site myinstants --find rampage
python download_voice.py --site myinstants --get "https://www.myinstants.com/en/instant/dota-rampage/"
```

ชื่อไฟล์: Dota = `<ID> - <คนพากย์> - <ข้อความ>.mp3` · Myinstants = `<ชื่อ> [<ID>].mp3`

> ตัวเชื่อมเว็บอยู่ใน [sources.py](sources.py) เพิ่มเว็บใหม่ได้โดยเขียนคลาสที่มี `search()` แล้วใส่ใน `SOURCES`
> เว็บ Dota อ่านจาก `src/voice_lines_list.html` เพราะหน้าแรกอยู่หลัง Cloudflare ดึงตรง ๆ ไม่ได้

## ปัญหาที่เจอบ่อย

| อาการ | แก้ |
|---|---|
| มีไฟล์ใน `sounds/` แต่หน้าโปรแกรมว่าง | โปรแกรมแสดงรายการจาก `config.json` ไม่ใช่จากโฟลเดอร์ — เวอร์ชันใหม่สแกนให้ตอนเปิดแล้ว ถ้ายังว่างให้กด "เพิ่มทั้งโฟลเดอร์" |
| เช็คว่ามองโฟลเดอร์ไหนอยู่ | โปรแกรมใช้ `sounds/` ที่อยู่**ข้างตัว exe** เสมอ — ถ้ารันจาก `dist/SoundSaoTer.exe` ก็คือ `dist/sounds/` ไม่ใช่โฟลเดอร์ source |
| ไม่เห็น CABLE ในรายการ | ยังไม่ได้รีสตาร์ตหลังติดตั้ง VB-CABLE / กด "รีเฟรชอุปกรณ์" |
| เห็น `CABLE Input` แต่เลือกแล้ว error | บางเครื่อง Windows ทิ้งรายการผีไว้ ตัวที่ใช้ได้จริงคือ `CABLE In 16ch` — โปรแกรมทดลองเปิดจริงก่อนเลือกให้อยู่แล้ว |
| ฮอตคีย์ถูกจองทั้งที่ไม่มีโปรแกรมอื่น | มี soundboard อีกหน้าต่างเปิดค้างอยู่ ปิดตัวเก่าก่อน |
| ฮอตคีย์ไม่ทำงาน | ปุ่มชนกับโปรแกรมอื่น — ดูแถบสถานะแล้วเปลี่ยนปุ่ม (ไม่ต้องใช้ admin) |
| กดปุ่มนั้นในเกมแล้วเกมไม่ตอบสนอง | ปกติ — Windows กินปุ่มที่ลงทะเบียนไว้ ให้เลือกปุ่มที่ไม่ได้ใช้ในเกม |
| คนอื่นได้ยินเบามาก | เพิ่ม Levels ของ CABLE Output ใน Windows + เพิ่มสไลเดอร์ "เสียงเข้าเกม" |
| เสียงแตก | ลดสไลเดอร์ลงต่ำกว่า 100% |
| พูดแล้วคนอื่นไม่ได้ยิน | ยังไม่ได้เลือก "ไมค์จริง (ส่งเข้าเกมด้วย)" ในโปรแกรม |
| เสียงพูดสะท้อน/หอน | เลือก CABLE Output เป็นไมค์จริงอยู่ ให้เปลี่ยนเป็นไมค์ตัวจริง |
| เปิดอุปกรณ์ไม่ได้ (error) | ลองเลือกอุปกรณ์ตัวเดียวกันแต่เป็น `[MME]` หรือ `[Windows DirectSound]` แทน WASAPI |

## ข้อควรรู้เรื่อง anti-cheat

โปรแกรมนี้ไม่แตะตัวเกมเลย — ไม่อ่าน/เขียน memory, ไม่ inject DLL, ไม่ hook DirectX,
ไม่ส่ง input ปลอม มันเป็นแค่โปรแกรมเล่นไฟล์เสียง ระดับเดียวกับ Discord หรือ OBS

ฮอตคีย์ใช้ `RegisterHotKey` ซึ่งเป็น API ที่เปิดเผยของ Windows ไม่ใช่ low-level hook
แบบที่โปรแกรม macro ใช้ และ VB-CABLE ก็เป็น signed driver ที่สตรีมเมอร์ใช้กันทั่วโลก

ความเสี่ยงจริงไม่ใช่ anti-cheat แต่เป็น **ระบบรีพอร์ต** — สแปมเสียงใส่ voice chat
เข้าข่าย harassment โดนรีพอร์ตเยอะ ๆ ก็โดน voice ban ได้ ใช้พอประมาณ
